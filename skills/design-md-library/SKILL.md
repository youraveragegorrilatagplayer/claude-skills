# DESIGN.md library

Each folder in `systems/<site>/DESIGN.md` describes one product's visual language: colors, type, spacing, components and rules. Folder names: list `systems/` to see them all.

How to use:
1. Pick the one or two systems closest to the direction the user wants and read only those files.
2. Borrow principles (contrast, rhythm, type scale, density, motion), not identity. Never reproduce a brand's logo, name, wordmark or exact signature look on a page that isn't theirs.
3. When the user wants a DESIGN.md for their own project, use the closest file as a structural template and fill it with their tokens.
